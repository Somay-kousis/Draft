**Draft is a privacy-first authorship verification system for writers.**

Instead of trying to determine whether a finished piece *looks* AI-generated, Draft records evidence of **how the piece was created**.

A writer writes normally. Draft runs in the background and captures non-content process signals such as writing activity, draft progression, edit history, paste events, and changes over time. The writer can then generate a verifiable **Proof of Authorship** without exposing their private drafts to a publisher, editor, or other third party.

## The Problem

AI-generated content has made it increasingly difficult for publishers to answer a simple question:

> **Did this person actually write this?**

Existing approaches generally fall into two categories:

* **AI detectors** — attempt to infer whether the final text was generated by AI.
* **Human verification systems** — often require identity-based or biometric verification.

Both approaches have limitations.

AI detection is probabilistic and can produce false positives. Identity verification proves *who someone is*, but not necessarily *who wrote the work*.

Draft takes a different approach:

> **Don't detect the human from the final text. Prove the human through the writing process.**

## How Draft Works

```text
Writer
  │
  ▼
Draft Plugin
  │
  ├── Writing activity
  ├── Draft progression
  ├── Edit history
  ├── Paste events
  └── Timestamps
  │
  ▼
Privacy-Preserving Event Log
  │
  ▼
Proof of Authorship
  │
  ▼
Writer shares proof with Publisher
  │
  ▼
Publisher verifies
```

The publisher does **not** need access to the writer's private drafting history.

Draft provides evidence about the process without exposing the underlying work.

## MVP

The first version deliberately stays simple.

### 1. Writing Plugin

A browser extension or writing-editor plugin that records:

* Number of words written over time
* Writing sessions
* Draft versions
* Major revisions
* Paste events
* Approximate writing velocity
* Timeline of document evolution

### 2. Local / Private Storage

Raw writing content should remain private wherever possible.

Draft should prioritize storing **process evidence rather than the actual text**.

### 3. Authorship Proof

When the work is complete, the writer generates a proof containing information such as:

```text
Work ID
Creation timeline
Number of writing sessions
Draft progression
Revision activity
Paste activity
Integrity signature
Verification timestamp
```

The writer can give this proof to a publisher.

### 4. Publisher Verification

The publisher receives the proof and can verify that the evidence has not been modified.

The publisher does not need to receive the writer's private drafts.

## What Draft Is Not

Draft is **not an AI detector**.

It does not claim:

> "This text is 94% human."

Instead, it attempts to establish:

> "There is verifiable evidence that this work was developed through this recorded writing process."

This distinction is fundamental to the project.

## Future: Draft Card

A later version can introduce a **Draft Card** for writers.

A writer finishes a piece and generates a portable authorship credential containing a cryptographically verifiable summary of its creation history.

The writer can attach the Draft Card when submitting work to:

* Publishers
* Magazines
* Competitions
* Universities
* Journalism organizations
* Literary platforms
* Freelance clients

The recipient verifies the card without receiving the writer's private drafting history.

## Design Principles

### Privacy First

The writer's private drafts should not become publisher-owned data merely because they want to prove authorship.

### Process Over Prediction

Draft focuses on observable creation history rather than attempting to classify text as "human" or "AI."

### Verifiable Evidence

Evidence should be tamper-resistant and independently verifiable.

### User Controlled

The writer decides when and with whom authorship evidence is shared.

## Important Limitation

A writing timeline alone cannot mathematically prove that a human wrote every character.

Someone could potentially manipulate the environment, paste text gradually, or use AI during the drafting process.

Therefore, Draft should present its output as **evidence of authorship/process**, not absolute proof of humanity.

This distinction will be critical for building a system that publishers can actually trust.

## Roadmap

### Phase 1 — MVP

* Browser extension
* Writing activity tracking
* Draft timeline
* Revision tracking
* Paste detection
* Local event storage
* Basic verification report

### Phase 2 — Proof System

* Cryptographic event signing
* Tamper-evident logs
* Portable Draft Cards
* Publisher verification portal

### Phase 3 — Privacy

* Minimize stored text
* Hash-based commitments
* Selective disclosure
* Privacy-preserving verification

### Phase 4 — Intelligent Analysis

A separate system can analyze the evolution between drafts to identify significant behavioral changes, including potential transitions from human-written material to AI-assisted writing.

This should **augment the authorship evidence**, not replace it with another black-box AI detector.

## Vision

AI has made the final product increasingly difficult to distinguish from human work.

Draft asks a different question:

> **Can we preserve evidence of the human process behind the work?**

The goal is to build a privacy-preserving layer of trust between **writers and the institutions that need to believe them**.
